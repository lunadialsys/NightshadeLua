To contribute to this project, use whatever tools you want. Yes, this means you _can_ use LLMs if you wish.

However, there is **one** rule:
**if you are contributing to this repo using a large language model, the code must not _look_ like it was written by a large language model.**

This means that if you use an LLM, you must _convince_ me that _no parts_ of your PR were written by the LLM. The easiest way to do this is to look over the generated code and rewrite by hand parts that look like "slop".
Note that this also applies to text that isn't source code, like commit messages or comments (because I find reading LLM-generated text incredibly grating).

If your code does not pass my scrutiny, and I get the impression that it was LLM-generated, I _will_ close your pull request with extreme prejudice. Repeat offenders will probably also get banned from the repo.

## But why though?
- I don't want to contribute to the slop-code epidemic.
- The code in this repository was written by hand, and I have a certain quality standard for what my own code should look like.
- It's my repository and I can do what I want.
